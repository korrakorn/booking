# 🏸 ก๊วนแบด: แอปลงชื่อนัดตีแบด

เว็บหน้าเดียวสำหรับให้เพื่อนกดว่าจะไปตีแบดหรือไม่ แอดมินจะได้รู้จำนวนคนก่อนจองคอร์ด

## ทำอะไรได้บ้าง
- **แอดมิน** (ใช้รหัส) สร้างนัดได้ โดยกำหนดชื่อนัด วันที่ เวลา สถานที่ จำนวนคนสูงสุด หมายเหตุ และ**รายชื่อคนที่ลงชื่อได้**
- **เพื่อน** เลือกชื่อตัวเองจากรายชื่อ แล้วกด ✅ ไป / 🤔 ไม่แน่ใจ / ❌ ไม่ไป (เปลี่ยนใจกดใหม่ได้ เว็บจะจำชื่อไว้ในเครื่อง)
- นับจำนวนคนให้อัตโนมัติ ถ้าคนเกินจำนวนสูงสุด คนที่กดทีหลังจะเข้า **คิวสำรอง**
- บอกคร่าว ๆ ว่าต้องจองกี่คอร์ด (คิดที่ 4–6 คนต่อคอร์ด)
- ปุ่ม **📋 สรุปส่ง LINE** คัดลอกสรุปรายชื่อพร้อมลิงก์ไปวางในกลุ่มได้ทันที
- ปุ่ม **🔗 คัดลอกลิงก์** ส่งลิงก์ที่เปิดมาแล้วเจอนัดนั้นเลย
- แอดมินปิด/เปิดรับชื่อ แก้ไขนัด ลบนัด หรือลบคำตอบของใครก็ได้
- ข้อมูลอัปเดตแบบเรียลไทม์ เพื่อนกดปุ๊บทุกคนเห็นปั๊บ

## ไฟล์
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด ค่าตั้งค่าอยู่ช่วงบนของ `<script>` (ส่วน "ตั้งค่าแอป") |

> ถ้ายังไม่ใส่ค่า Firebase แอปจะเข้า **โหมดทดลอง** เก็บข้อมูลไว้ในเครื่องตัวเองเท่านั้น ใช้ลองดูหน้าตาได้ แต่เพื่อนจะไม่เห็น

## ขั้นที่ 1: สร้างฐานข้อมูล Firebase (ฟรี)
GitHub Pages เก็บได้แค่ไฟล์ ไม่มีที่เก็บข้อมูลส่วนกลาง เลยต้องใช้ Firebase เก็บคำตอบของทุกคน

1. ไปที่ https://console.firebase.google.com แล้วกด **Add project** ตั้งชื่ออะไรก็ได้ (ปิด Google Analytics ได้)
2. เมนูซ้าย **Build → Realtime Database → Create Database**
   - Location: เลือก **Singapore (asia-southeast1)** จะใกล้ไทยที่สุด
   - เลือก **Start in test mode** แล้วกด Enable
3. ไปที่แท็บ **Rules** วางโค้ดนี้แล้วกด **Publish** (test mode จะหมดอายุใน 30 วัน ต้องตั้ง Rules เองแบบนี้)
   ```json
   {
     "rules": {
       "events": {
         ".read": true,
         ".write": true
       }
     }
   }
   ```
4. กดรูปเฟือง ⚙️ → **Project settings** → เลื่อนลงไปที่ **Your apps** → กดไอคอน **`</>`** (Web) ตั้งชื่อแอป แล้วกด Register
5. จะเห็นโค้ด `const firebaseConfig = { ... }` ให้คัดลอกค่าข้างในไปใส่ใน `FIREBASE_CONFIG` ใน `index.html`
   - เช็กว่ามี `databaseURL` ด้วย หน้าตาประมาณ `https://ชื่อโปรเจกต์-default-rtdb.asia-southeast1.firebasedatabase.app` (ถ้าไม่มี ให้คัดลอกจากหน้า Realtime Database ด้านบนสุด)

## ขั้นที่ 2: แก้ส่วนตั้งค่าใน `index.html`

```js
export const FIREBASE_CONFIG = { apiKey: 'AIza...', databaseURL: 'https://...', ... };
```

## ขั้นที่ 3: ขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub (เช่น `badminton`) ตั้งเป็น **Public**
2. อัปโหลด `index.html` และ `README.md` (กด **Add file → Upload files**)
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `/ (root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ประมาณ `https://ชื่อผู้ใช้.github.io/badminton/` ส่งลิงก์นี้ให้เพื่อนได้เลย

## วิธีใช้
1. แอดมินกด **แอดมิน** มุมขวาบน → ใส่รหัส → กด **+ สร้างนัด**
2. ใส่วันที่ สถานที่ และรายชื่อเพื่อน (บรรทัดละชื่อ) → บันทึก
   - นัดถัดไปจะดึงรายชื่อ สถานที่ และเวลาจากนัดล่าสุดมาให้อัตโนมัติ
3. กด **📋 สรุปส่ง LINE** แล้ววางในกลุ่ม เพื่อนกดลิงก์ → เลือกชื่อ → กดไป/ไม่ไป
4. พอได้จำนวนคนแล้วก็ไปจองคอร์ด แล้วกด **🔒 ปิดรับชื่อ**

## ⚠️ เรื่องความปลอดภัย
- รหัสแอดมินอยู่ในไฟล์ `index.html` ซึ่งใครเปิดดูโค้ดเว็บก็เห็น จึงใช้ได้แค่**ซ่อนปุ่มแอดมิน**จากคนทั่วไป ไม่ได้กันคนที่ตั้งใจแกะโค้ด
- Rules ข้างบนเปิดให้ใครที่มีลิงก์อ่าน/เขียนได้ ใช้ในกลุ่มเพื่อนได้สบาย แต่อย่าเก็บข้อมูลส่วนตัวสำคัญ (เบอร์โทร ฯลฯ) ไว้ในนี้
- ถ้าอยากให้ล็อกจริงจัง ต้องเพิ่ม Firebase Authentication (เช่น ให้แอดมินล็อกอินด้วย Google) แล้วเขียน Rules ให้เฉพาะแอดมินสร้างนัดได้
